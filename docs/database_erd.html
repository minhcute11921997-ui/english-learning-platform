    USERS {
        int id PK "Khóa chính User"
        string username "Tên tài khoản (unique)"
        string email "Email đăng nhập (unique)"
        string full_name "Họ và tên học viên"
        string role "admin | learner | group_owner"
        int initial_level "Điểm đầu vào (0 - 100)"
        datetime last_login_at "Đăng nhập lần cuối"
    }

    USER_VOCAB_LISTS {
        int id PK "Khóa chính Bộ từ"
        int user_id FK "Thuộc sở hữu của User nào"
        string name "Tên bộ từ (Ví dụ: Từ khó nhớ)"
        text description "Ghi chú mục đích của bộ từ"
        string color "Mã màu nhận diện"
    }

    USER_VOCAB_LIST_ITEMS {
        int id PK "Khóa chính dòng liên kết"
        int list_id FK "Mã bộ danh sách (user_vocab_lists.id)"
        int vocabulary_id FK "Mã từ vựng (vocabularies.id)"
    }

    USER_VOCAB_PROGRESS {
        int id PK "Khóa chính tiến độ"
        int user_id FK "Mã học viên"
        int vocabulary_id FK "Mã từ vựng"
        string status "new | learning | mastered"
        int correct_count "Số lần ôn đúng"
        int incorrect_count "Số lần ôn sai"
        float ease_factor "Hệ số dễ (SM-2, mặc định 2.5)"
        int interval_days "Khoảng cách ngày ôn kế tiếp"
        datetime next_review_at "Ngày giờ ôn tập tiếp theo"
    }

    REVIEW_SCHEDULES {
        int id PK "Khóa chính lịch hẹn"
        int user_id FK "Mã học viên cần ôn"
        int vocabulary_id FK "Mã từ vựng cần ôn"
        datetime scheduled_at "Ngày đến hạn ôn (Due date)"
        boolean is_completed "Đã ôn xong chưa"
        string source "personal | group"
    }

    LEVEL_ASSESSMENTS {
        int id PK "Khóa chính bài test"
        int user_id FK "Mã học viên"
        int score "Điểm đạt được"
        int total_questions "Tổng số câu hỏi"
        string assessed_level "Trình độ đánh giá"
        datetime completed_at "Thời gian hoàn thành"
    }

    VOCABULARIES {
        int id PK "Mã từ vựng hệ thống"
        string word "Từ tiếng Anh"
        string pronunciation "Phiên âm IPA"
        string part_of_speech "noun | verb | adj | adv"
        string meaning_vi "Nghĩa tiếng Việt"
        string difficulty "easy | medium | hard"
    }

Từ Điển Cấu Trúc Các Bảng (Schema Reference)

Mô tả chi tiết mục đích, khóa chính (PK), khóa ngoại (FK) và kiểu dữ liệu của từng bảng.

users Tài khoản

Lưu thông tin đăng nhập, phân quyền và điểm trình độ ban đầu của người dùng.

id: INT (PK, Auto Inc)
username: VARCHAR(50) [UNIQUE]
email: VARCHAR(100) [UNIQUE]
password_hash: VARCHAR(255)
full_name: VARCHAR(100)
role: ENUM('admin','learner','group_owner')
initial_level: INT (0 - 100)
last_login_at: DATETIME
user_vocab_lists Sổ từ cá nhân

Lưu các bộ danh sách từ do từng học viên tự tạo (ví dụ: "Từ khó nhớ", "Từ vựng IELTS").

id: INT (PK, Auto Inc)
user_id: INT (FK -> users.id)
name: VARCHAR(150)
description: TEXT
color: VARCHAR(30)
user_vocab_list_items Cầu nối N - N

Bảng trung gian Nhiều - Nhiều: 1 từ vựng có thể được thêm vào nhiều bộ danh sách khác nhau.

id: INT (PK, Auto Inc)
list_id: INT (FK -> user_vocab_lists.id)
vocabulary_id: INT (FK -> vocabularies.id)
INDEX UNIQUE(list_id, vocabulary_id)
user_vocab_progress Thuật toán SM-2

Lưu trạng thái ghi nhớ của từng User cho từng từ vựng theo thuật toán SuperMemo-2 (Anki).

id: INT (PK, Auto Inc)
user_id: INT (FK -> users.id)
vocabulary_id: INT (FK -> vocabularies.id)
status: ENUM('new','learning','mastered')
correct_count, incorrect_count: INT
ease_factor: FLOAT (mặc định 2.5)
interval_days: INT (khoảng cách ngày ôn)
next_review_at: DATETIME
review_schedules Hàng đợi SRS

Hàng đợi lịch hẹn ngày cần ôn tập. Hệ thống truy vấn các từ đến hạn (due) để hiển thị trong ngày.

id: INT (PK, Auto Inc)
user_id: INT (FK -> users.id)
vocabulary_id: INT (FK -> vocabularies.id)
scheduled_at: DATETIME
is_completed: BOOLEAN
completed_at: DATETIME
source: ENUM('personal','group')
vocabularies Kho từ vựng

Kho dữ liệu từ vựng tiếng Anh gốc dùng chung cho toàn hệ thống.

id: INT (PK, Auto Inc)
topic_id: INT (FK -> topics.id)
word: VARCHAR(100)
pronunciation: VARCHAR(100)
part_of_speech: ENUM('noun','verb','adjective'...)
meaning_vi: VARCHAR(255)
difficulty: ENUM('easy','medium','hard')
is_approved: BOOLEAN
readings & questions Đọc hiểu

Bài đọc tiếng Anh kèm bộ câu hỏi trắc nghiệm A, B, C, D và giải thích chi tiết.

readings.id: INT (PK)
title, content: TEXT
word_count, estimated_time_minutes: INT
questions.id: INT (PK)
reading_id: INT (FK)
question_text, options (JSON)
correct_option: INT (0-3)
explanation_vi: TEXT
user_reading_attempts Lịch sử làm bài

Lịch sử thi đọc hiểu: điểm số, % đúng, thời gian làm và từng câu trả lời đúng/sai.

id: INT (PK, Auto Inc)
user_id: INT (FK -> users.id)
reading_id: INT (FK -> readings.id)
score, total_questions: INT
percentage: FLOAT
time_spent_seconds: INT
completed_at: DATETIME

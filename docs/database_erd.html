Chi Tiết Các Bảng & Cơ Chế Cách Ly Dữ Liệu

Giải thích nguyên lý lưu trữ phân tầng giữa dữ liệu dùng chung và dữ liệu cá nhân của từng học viên.

users Identity

Lưu tài khoản đăng nhập, phân quyền quản trị (admin / learner / group_owner) và trình độ khởi điểm.

id: INT (PK)
username, email, password_hash
role: ENUM('admin','learner','group_owner')
initial_level: INT (0-100)
learning_goal: VARCHAR
user_vocab_lists Custom Sets

Các bộ từ vựng cá nhân do học viên tự tạo (ví dụ: "Từ khó nhớ", "Từ vựng IELTS").

id: INT (PK)
user_id: INT (FK -> users.id)
name: VARCHAR(150)
description: TEXT
color: VARCHAR(30)
user_vocab_list_items Many-to-Many

Bảng cầu nối Nhiều - Nhiều: Cho phép 1 từ vựng nằm trong nhiều bộ danh sách khác nhau.

id: INT (PK)
list_id: INT (FK -> user_vocab_lists)
vocabulary_id: INT (FK -> vocabularies)
UNIQUE(list_id, vocabulary_id)
user_vocab_progress SM-2 Algorithm

Lưu trạng thái trí nhớ và các hệ số toán học của thuật toán ghi nhớ ngắt quãng SuperMemo-2.

id: INT (PK)
user_id, vocabulary_id (UNIQUE)
status: ENUM('new','learning','mastered')
ease_factor: FLOAT (mặc định 2.5)
interval_days: INT (khoảng cách ngày)
next_review_at: DATETIME
review_schedules SRS Queue

Hàng đợi lịch hẹn ôn tập. Truy vấn nhanh danh sách "Từ cần ôn hôm nay" theo ngày đáo hạn.

id: INT (PK)
user_id, vocabulary_id
scheduled_at: DATETIME
is_completed: BOOLEAN
source: ENUM('personal','group')
user_reading_attempts Reading History

Lịch sử làm bài đọc hiểu: điểm số, tỷ lệ phần trăm đúng, thời gian làm và chi tiết từng câu trả lời.

id: INT (PK)
user_id, reading_id
score, total_questions: INT
percentage: FLOAT
time_spent_seconds: INT
